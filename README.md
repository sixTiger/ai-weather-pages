# AI 天气查询页面

两个单文件天气查询网页，均在浏览器中直接调用 Open-Meteo 的公开接口，不需要后端服务或 API 密钥。

- `weather-query.html`：天气页面 A
- `weather.html`：天气页面 B
- `index.html`：版本选择页

发布目标：GitHub Pages 与 Cloudflare Pages。

## 在线体验

- GitHub 仓库：https://github.com/sixTiger/ai-weather-pages
- GitHub Pages：https://sixtiger.github.io/ai-weather-pages/
- Cloudflare Pages：https://ai-weather-pages.pages.dev/

两个托管地址都包含以下页面：

- `weather-query.html`：天气页面 A
- `weather.html`：天气页面 B

Cloudflare Pages 已连接本仓库的 `main` 分支。后续推送到 `main` 后，Cloudflare 会自动重新部署。
